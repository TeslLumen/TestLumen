# TestLumen 测试分析AI-Agent 

一款基于大语言模型的智能测试分析工具，支持需求分析、测试点生成、测试用例生成等核心场景。

## 1. 产品简介

**TestLumen** 是一款面向软件测试领域的 AI Agent 工具，旨在通过大语言模型帮助测试工程师快速完成以下工作：

- 📋 **需求分析**：从原始需求文档中提取关键信息
- 🎯 **测试点生成**：基于需求自动推导测试点
- ✍️ **测试用例生成**：根据测试点生成结构化测试用例
- 📚 **知识库管理**：沉淀业务知识，提升生成质量
- 📤 **结果导出**：支持 Excel / JSON 等格式导出

### 核心特性

- ✅ **多角色支持**：通用用例设计师、场景用例设计师、安全用例设计师等多种角色
- ✅ **多模型兼容**：支持 OpenAI 兼容协议的所有大模型（如 DeepSeek、Qwen、GPT等）
- ✅ **多模态能力**：模型支持TestLumen工具就支持
- ✅ **模板可定制**：导出字段可自由勾选
- ✅ **支持试用**：提供 30 天免费试用

## 2. 安装与启动

### 2.1 系统要求

- **操作系统**：Windows 10/11 或 macOS
- **内存**：建议 8GB 及以上
- **硬盘**：至少 2GB 可用空间
- **网络**：需要联网（用于调用大模型 API）

### 2.2 启动应用

双击桌面 TestLumen 图标即可启动应用程序。

启动后将进入主界面，但**首次使用需要先完成激活**。

### 3.1 激活界面说明

首次启动 TestLumen 时，系统会自动弹出 **"软件激活"** 对话框，要求输入激活码。

**激活码类型：**

- **试用码**：在有效期内使用，激活后可用 **30 天**
- **正式码**：必须在购买当月激活，激活后开始计算有效期

### 3.2 激活步骤

1. 联系购买渠道获取激活码
2. 在激活对话框中输入激活码
3. 点击 **"激活"** 按钮
4. 弹出 **"激活成功"** 对话框，提示到期日

**激活成功后：**

- ✅ 弹出"试用激活成功！到期日：YYYY-MM-DD"提示
- ✅ 所有功能解锁可用

## 4. 首次配置（开箱即用）

激活完成后，正式使用前需要完成三项**一次性配置**。这三项配好后就可以一直使用，无需重复设置：

| 配置项 | 是否必选 | 说明 |
|--------|----------|------|
| **模型配置** | ✅ 必选 | 没有模型就跑不了 AI |
| **知识库维护** | ⭐ 推荐 | 有知识库，生成的用例更贴业务 |
| **导出模板配置** | ⭐ 推荐 | 控制导出 Excel 的字段 |

### 4.1 模型配置

TestLumen 支持接入各种 OpenAI 兼容协议的大模型服务。

#### 进入模型配置
<img width="921" height="441" alt="4-模型配置" src="https://github.com/user-attachments/assets/d7102e25-3584-4c00-b988-e86eece67f1e" />

主界面 → 中间栏 **"模型"** 模块 → 点击 **"选择"** 按钮 → 弹出"选择模型"对话框。

#### 模型操作

**选择模型对话框** 提供以下操作：

- **新增**：添加新的模型配置
- **修改**：编辑现有模型
- **删除**：删除不需要的模型

#### 新增模型

点击 **"新增"** 按钮，弹出"新增模型"对话框，需填写以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| **模型名称** | 模型 ID | `qwen3-235b-a22b-instruct-2507-20` |
| **API Key** | 模型服务的密钥 | `sk-xxxxxxxxxxxxxxxx` |
| **Base URL** | API 服务地址 | `https://api.example.com/v1` |
| **支持多模态** | 勾选后支持图片输入 | ☑ / ☐ |

填写完成后点击 **"确定"** 保存。

#### 多模态说明

- ✅ **勾选"支持多模态"**：可在输入框中粘贴图片，AI 将识别图片内容
- ❌ **未勾选**：仅支持纯文本输入

**示例：**

> **系统名称**：电商平台
>
> **系统描述**：平台涉及四类核心角色并对应权限边界：游客只能浏览搜索、查看……

## 8. 常见问题

### Q1：激活码输入后提示无效怎么办？

**A**：请检查：
- 激活码是否完整复制（无空格、无换行）
- 激活码是否在有效期内

仍有问题请联系客服（微信：TestLumen）。

### Q2：启动生成后没有反应？

**A**：请按以下顺序排查：
1. 检查底部状态栏"API：正常"是否为绿色
2. 确认已选择模型（不能是默认的"model-name"）
3. 确认"请求输入"框内有内容
4. 检查网络连接是否正常
5. 验证 API Key 是否有效

### Q3：如何切换不同 AI 模型？

**A**：在主界面点击模型模块的 **"选择"** 按钮，在弹窗中选择目标模型。如未配置，请先到 **系统设置 → 模型** 中新增。

### Q4：知识库里的内容如何被 AI 使用？

**A**：在"上下文"模块的 **"关联系统"** 中选择对应的系统名称，AI 生成时会自动引用该系统的知识库内容。

### Q5：导出 Excel 时某些字段缺失？

**A**：请检查对应模板（测试点模板 / 测试用例模板）的字段勾选状态，未勾选的字段不会导出。

### Q6：导出 Excel 时报错Column或limit？

**A**：检查输出内容是否在中间包含中括号或····json类似内容，保证输出内容为完整json内容。

### Q6：试用到期后还能用吗？

**A**：试用到期后需购买正式码激活。激活后按正式码有效期使用。

### Q7：如何同时处理多个需求文档？

**A**：可点击 **"新建窗口"** 打开多个工作窗口，并行处理不同需求。

### Q8：生成的内容不符合预期怎么办？

**A**：可尝试以下优化方法：
- 调整"行业"和"关联系统"选择
- 切换不同的 AI 角色
- 完善知识库中的系统描述
